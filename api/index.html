cert/map API

The certification data as plain JSON: prices, levels, prerequisites, study plans and comparisons for 320 cybersecurity certifications. Free to use, no key, callable from a browser.

Open the entry point OpenAPI description

Endpoints

URLReturns
/api/v1/index.jsonCounts and the URL of every endpoint
/api/v1/certs.jsonEvery certification, summarised: vendor, domain, level, price
/api/v1/certs/{id}.jsonOne certification in full, with its study plan and comparisons
/api/v1/vendors.jsonVendors and the ids of their certifications
/api/v1/domains.jsonDomains and the ids of their certifications
/api/v1/comparisons.jsonPairs that have a comparison page, with the page in each language
/api/v1/paths.jsonPreset role paths with cost and study-time totals

Example

Show the current exam price of a certification on your own page:

const res = await fetch("https://certmap.dev/api/v1/certs/oscp.json");
const { certification } = await res.json();
console.log(certification.acronym, certification.price_usd);   // OSCP+ 1749

How it works

  • It is static. The files are regenerated whenever the dataset changes, so there is nothing to query: fetch a file and filter it on your side.
  • Cross-origin requests are allowed, so it works from client-side code on any site.
  • Responses are cached for about ten minutes. Please cache on your side too instead of fetching on every page view.
  • URLs under /api/v1/ keep their shape. A breaking change would be published as v2.
  • price_usd is the exam list price in US dollars: null when the vendor does not publish one, 0 when it is free. price_verified_at is the date it was last seen on the vendor's page.

Licence and attribution

The data is published under CC BY 4.0. You can use it in any project, commercial or not, as long as you credit cert/map with a link to certmap.dev. Prices change without notice, so tell your readers to confirm with the vendor.

The whole dataset is also available as single files: certs.json, certs.csv, resources.csv and comparisons.csv.
