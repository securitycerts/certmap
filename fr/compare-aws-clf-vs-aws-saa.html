Ce qui les distingue

  • L'examen le moins cher est CLF-C02 : 100 $US contre 150 $US pour SAA-C03, soit 50 $US d'écart.
  • Niveau débutant pour CLF-C02, niveau intermédiaire pour SAA-C03. Des deux, on commence en général par CLF-C02.
  • Les deux examens sont écrits ou à choix multiples.
  • L'examen SAA-C03 est plus long : 130 minutes contre 90 minutes pour CLF-C02.
  • Les deux se renouvellent tous les 3 ans.
  • Les deux sont délivrées par AWS.
