Les différences entre SAA-C03 et SAP-C03

  • L'examen le moins cher est SAA-C03 : 150 $US contre 300 $US pour SAP-C03, soit 150 $US d'écart.
  • Niveau intermédiaire pour SAA-C03, niveau expert pour SAP-C03. Des deux, on commence en général par SAA-C03.
  • Les deux examens sont écrits ou à choix multiples.
  • L'examen SAP-C03 est plus long : 180 minutes contre 130 minutes pour SAA-C03.
  • Les deux se renouvellent tous les 3 ans.
  • SAA-C03 est un prérequis pour SAP-C03.
  • Les deux sont délivrées par AWS.
