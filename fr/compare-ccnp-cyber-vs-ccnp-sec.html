Les différences entre CCNP Cybersecurity et CCNP Security

  • Les deux examens coûtent 400 $US.
  • Les deux sont classées au niveau avancé sur la carte.
  • Les deux examens sont écrits ou à choix multiples.
  • Les deux se renouvellent tous les 3 ans.
  • CCNP Security est reconnue par le cadre DoD 8140. CCNP Cybersecurity n'y figure pas.
  • Les deux sont délivrées par Cisco.
