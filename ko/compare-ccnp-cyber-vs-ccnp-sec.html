CCNP Cybersecurity vs CCNP Security

CCNP Cybersecurity, CCNP Security 중 무엇을 선택할까요?

CCNP Cybersecurity 자격증과 Cisco Certified Network Professional Security 자격증을 나란히 비교합니다. 응시료, 시험 형식, 시험 시간, 갱신, 선수 자격을 cert/map의 최신 데이터로 정리했습니다.

CCNP Cybersecurity, CCNP Security 차이점

  • 두 시험 모두 응시료는 US$400입니다.
  • 두 자격증 모두 로드맵에서 고급 단계에 있습니다.
  • 두 시험 모두 필기 또는 객관식입니다.
  • 두 자격증 모두 3년마다 갱신해야 합니다.
  • CCNP Security 자격증은 DoD 8140에서 인정됩니다. CCNP Cybersecurity 자격증은 목록에 없습니다.
  • 두 자격증 모두 Cisco에서 발급합니다.
