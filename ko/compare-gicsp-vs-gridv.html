GICSP vs GRID

GICSP, GRID 중 무엇을 선택할까요?

GIAC Global Industrial Cyber Security Professional 자격증과 GIAC Response and Industrial Defense 자격증을 나란히 비교합니다. 응시료, 시험 형식, 시험 시간, 갱신, 선수 자격을 cert/map의 최신 데이터로 정리했습니다.

GICSP, GRID 차이점

  • 두 시험 모두 응시료는 US$999입니다.
  • GICSP 자격증은 고급 단계, GRID 자격증은 전문가 단계입니다. 둘 중에서는 보통 GICSP 자격증부터 시작합니다.
  • 두 시험 모두 필기 또는 객관식입니다.
  • GICSP 시험이 더 깁니다. GICSP 시험은 180분, GRID 시험은 120분입니다.
  • 두 자격증 모두 4년마다 갱신해야 합니다.
  • 두 자격증 모두 GIAC에서 발급합니다.

자주 묻는 질문

GICSP 시험과 GRID 시험 중 어느 쪽이 더 저렴한가요?

두 시험 모두 응시료는 US$999입니다.

GICSP 자격증과 GRID 자격증 중 어느 쪽이 더 높은 단계인가요?

cert/map은 GICSP 자격증을 고급 단계, GRID 자격증을 전문가 단계로 분류합니다.

GICSP 자격증과 GRID 자격증은 만료되나요?

두 자격증 모두 4년마다 갱신해야 합니다.

GICSP 시험과 GRID 시험은 실습형인가요?

GICSP: 필기 또는 객관식. GRID: 필기 또는 객관식.
