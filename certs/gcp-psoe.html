Google Cloud Professional Security Operations Engineer PSOE

Covers detection engineering, threat hunting, incident response, data management and platform operations with Google Cloud security tooling. Multiple choice exam of 50 to 60 questions.

PSOE is an advanced-level Security Operations certification from Google. The exam costs $200. The exam runs for 120 minutes. It renews every 2 years.
