Certified Windows Internals Red Team Operator CWI-RTO

Certification on Windows internals for offensive work, covering Win32 and NT APIs, kernel data structures and debugging with WinDbg. Assessed by a task-based exam with no fixed end date, submitted as a PDF report.

CWI-RTO is an advanced-level Exploitation certification from CyberWarFare Labs. The exam costs $29. It does not expire.
