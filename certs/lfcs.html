Linux Foundation Certified System Administrator LFCS

Online proctored performance-based exam in which candidates solve Linux system administration tasks from the command line.

LFCS is an intermediate-level *nix certification from Linux Foundation. The exam costs $445. The exam runs for 120 minutes. It renews every 2 years.
