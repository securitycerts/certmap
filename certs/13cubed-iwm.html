Investigating Windows Memory IWM

Windows memory forensics covering memory structures, acquisition, pagefile analysis and analysis with Volatility, MemProcFS and WinDbg. Certification is earned by passing the course Knowledge Assessment, which has a multiple-choice part and a hands-on practical part; it does not expire.

IWM is an intermediate-level Forensics certification from 13Cubed. The exam costs $795. It does not expire.
