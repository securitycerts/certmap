AWS certifications at a glance

How many AWS certifications are there?

cert/map lists 7 AWS certifications: 1 beginner, 2 intermediate, 2 advanced, 2 expert.

How much do AWS certifications cost?

Published exam prices run from $100 (CLF-C02) to $300 (SAP-C03).

Which AWS certification should I start with?

The lowest tier on the roadmap is beginner, and CLF-C02 (AWS Certified Cloud Practitioner) is the usual entry point there.

Do AWS certifications expire?

Yes. All of them have a renewal cycle, for example CLF-C02 every 3 years.

Are AWS exams hands-on?

The AWS exams listed here are written or multiple choice.
