University of Colorado Fundamentals of Computer Network Security Specialization CU NetSec

Four-course University of Colorado System specialization covering secure system design, applied cryptography and PKI, penetration testing basics, and firewalls and intrusion detection. Course-based certificate assessed through projects on cloud instances, with no proctored exam.

CU NetSec is an intermediate-level Communication & Network Security certification from Coursera. The vendor does not publish a standalone exam price. It does not expire.
