Altered Security certifications at a glance

How many Altered Security certifications are there?

cert/map lists 5 Altered Security certifications: 2 intermediate, 1 advanced, 2 expert.

How much do Altered Security certifications cost?

Published exam prices run from $249 (CRTP) to $449 (CETP).

Which Altered Security certification should I start with?

The lowest tier on the roadmap is intermediate, and CRTP (Certified Red Team Professional) is the usual entry point there.

Do Altered Security certifications expire?

Yes. All of them have a renewal cycle, for example CARTP every 3 years.

Are Altered Security exams hands-on?

Yes. Every Altered Security exam listed here is practical and performance-based.
