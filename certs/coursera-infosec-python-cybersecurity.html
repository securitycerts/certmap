Infosec Python for Cybersecurity Specialization Infosec Python

Five-course Infosec specialization on writing Python scripts to automate offensive and defensive security tasks, organised around MITRE ATT&CK and Shield use cases. Course-based certificate assessed through coding projects, with no proctored exam.

Infosec Python is an intermediate-level Security Operations certification from Coursera. The vendor does not publish a standalone exam price. It does not expire.
