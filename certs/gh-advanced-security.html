GitHub Advanced Security GH-500

Exam GH-500 on using GitHub Advanced Security to secure code, secrets and dependencies, covering secret protection, supply chain security and code scanning with CodeQL.

GH-500 is an intermediate-level Software Security certification from GitHub. The vendor does not publish a standalone exam price. The exam runs for 100 minutes. It renews every 2 years.
