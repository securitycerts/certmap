AWS Certified Security Specialty SCS-C03

AWS security specialty certification (exam SCS-C03) covering threat detection, IAM, data protection and incident response.

SCS-C03 is an advanced-level Cloud/SysOps certification from AWS. The exam costs $300. The exam runs for 170 minutes. It renews every 3 years.
