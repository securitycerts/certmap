Kubernetes and Cloud Native Security Associate KCSA

Entry-level multiple choice exam on Kubernetes and cloud native security fundamentals. Online and proctored, with no prerequisites.

KCSA is a beginner-level Cloud/SysOps certification from CNCF. The exam costs $250. The exam runs for 90 minutes. It renews every 2 years.
