GIAC Public Cloud Security GPCS

Multi-cloud security certification covering AWS, Azure and GCP.

GPCS is an intermediate-level Cloud/SysOps certification from GIAC. The exam costs $999. The exam runs for 120 minutes. It renews every 4 years.
