Google Cloud Cybersecurity Professional Certificate GCP Cyber

Five-course entry-level program on cloud security with Google Cloud: risk management, identity and access, threat detection, and incident response using tools such as Security Command Center. Course-based certificate assessed through hands-on labs, with no proctored exam.

GCP Cyber is a beginner-level Cloud/SysOps certification from Coursera. The vendor does not publish a standalone exam price. It does not expire.
