TCM Security certifications at a glance

How many TCM Security certifications are there?

cert/map lists 9 TCM Security certifications: 3 beginner, 5 intermediate, 1 advanced.

How much do TCM Security certifications cost?

Published exam prices run from $249 (PJPT) to $499 (PWPP).

Which TCM Security certification should I start with?

The lowest tier on the roadmap is beginner, and PJPT (Practical Junior Penetration Tester) is the usual entry point there.

Do TCM Security certifications expire?

None of the TCM Security certifications listed here expires.

Are TCM Security exams hands-on?

8 of the 9 are assessed with a practical, performance-based exam; the others are written or multiple choice.
